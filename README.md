# UnitWorks

Fast, precise unit conversion for engineers: length, mass, pressure, energy and temperature.

- 5 categories, 41 units, exact SI constants
- Two-way editing, unit swap, copy, adjustable precision (4–15 significant digits)
- Recent conversions and light/dark mode, saved in your browser
- Single `index.html`, no build step, runs fully client-side
